# Jasmine Ajax 5.0.0 Release Notes

## Summary

This release updates jasmine-ajax to work with jasmine-core 7.x.

## Breaking Changes

* The set of supported browsers has changed. In particular, Internet Explorer
  and PhantomJS are no longer supported. See the table below for details about
  other browsers. Any future release releases of jasmine-ajax will follow
  [Jasmine's browser support policy](https://jasmine.github.io/pages/faq.html#browser-and-node-versions).
* Bower support has been removed.
* jasmine-ajax internals are no longer exposed via `getJasmineRequireObj()`.

## New Features

* Compatibility with jasmine-core 7.x as well as older and (hopefully) future
  versions. jasmine-ajax no longer depends on jasmine-core to do anything more
  than create a global `jasmine` object.

## Internal improvements

* Modernized build system.
* Removed residual code for Node support, which had been added in 3.3.0 and
  disabled in 3.3.1.

## Supported Browsers

This version has been tested in the following browsers.

| Browser | Supported versions |
|---------|--------------------|
| Safari  | 26.5**             |
| Chrome  | 149*               |
| Firefox | 140, 151*          |
| Edge    | 148*               |

\* Evergreen browser. Each version of jasmine-ajax is tested against the latest
version available at release time.<br>
\** Supported on a best-effort basis. Support for these versions may be dropped
if it becomes impractical, and bugs affecting only these versions may not be
treated as release blockers.
